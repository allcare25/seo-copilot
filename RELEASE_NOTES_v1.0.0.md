# SEO Copilot v1.0.0

SEO Copilot v1.0.0 is the first public free release.

## Highlights

- Google Search Console integration
- 4–20 position improvement opportunity analysis
- AI title and meta description suggestions
- AI FAQ and internal-link suggestions
- AI improvement draft generation
- LLMO / AEO checks and improvement suggestions
- URL Inspection-based index status checking
- Search performance history and effect measurement
- Gemini and Groq support

## Deliberately excluded from v1.0.0

- GA4 integration
- Competitor analysis
- Backlink monitoring/acquisition support
- AI image generation
- Notifications
- Background processing queue
- Google Indexing API registration requests
- Automatic indexing requests

## Important

This release is provided without a guarantee of search ranking or traffic improvements. Review AI-generated content before publishing it. External API quotas, pricing, models, terms, and availability are controlled by the respective providers and may change.
